The Internet and the Web

≈ 1.5 min

The Internet

A global network of networks. It is the hardware: cables, routers and connections that link computers around the world.

The World Wide Web

A collection of web pages and websites that you view in a browser. It is a service that uses the Internet.

Common mistake

The Internet and the Web are not the same thing. Email, online gaming and video calls also use the Internet, but they are not the Web.

Think of it like this: the Internet is the road network. The Web is one kind of traffic that travels on it, like delivery vans. Email and games are other traffic on the same roads.

Parts of a web address (URL)

https://www.greenfieldlibrary.org/books/fiction
Protocol: the set of rules used to transfer the page. The s in https means secure (encrypted). Domain name: the name of the website, which identifies the web server. Path: the exact folder or page on that website. It comes after the first single /.

Network types and models

≈ 1.5 min
LAN (Local Area Network)WAN (Wide Area Network)
AreaSmall area, usually one site or buildingLarge area: across towns, cities or countries
HardwareUsually owned by the organisationOften uses connections rented from telecoms companies
ExampleA sports centre's computersThe Internet is the biggest WAN

Common mistake

LAN or WAN depends on geographical distance, not how many computers there are. A site with 2,000 computers in one place is still a LAN.

Client-server

  • A dedicated server stores files, manages user accounts and controls security.
  • Clients (users' computers) send requests to the server.
  • Files can be reached from any computer on the network, and backups happen centrally.
  • Drawbacks: servers are expensive, and if the server fails, users cannot reach their files.

Peer-to-peer

  • No dedicated server. Every computer is equal (a "peer").
  • Computers share files directly with each other.
  • Cheap and simple to set up, but there are no central backups and security is harder to manage.

Network hardware

≈ 2 min

NIC (Network Interface Card)

The hardware inside a device that lets it connect to a network, by cable (Ethernet) or wirelessly (Wi-Fi). Each NIC has a unique MAC address.

Switch

Connects devices within a LAN. It sends data only to the device it is meant for, not to everyone.

Router

Connects different networks together, for example a home network and the Internet. It uses IP addresses to direct data between networks.

WAP (Wireless Access Point)

Lets wireless devices join a wired network. It is plugged into the wired network by cable and gives out a Wi-Fi signal.

How a switch gets data to the right device

  • Every device's NIC has a unique MAC address (for example 3C:22:FB:9A:10:7E).
  • The switch keeps a table that matches each MAC address to one of its ports.
  • When data arrives, the switch reads the destination MAC address, looks it up, and forwards the data only to that port.

Mobile connectivity

≈ 1.5 min

In 3G, 4G and 5G, the G stands for Generation. Each generation added something new:

GenWhat it brought
1GAnalogue voice calls only
2GDigital calls and SMS text messages
3GMobile internet, web browsing and video calls
4GMuch faster speeds: HD video streaming and online gaming on the go
5GVery high bandwidth, very low latency, and many devices connected at once (smart devices)

Bandwidth

The amount of data that can be sent per second. Higher bandwidth means more data arrives each second.

Latency

The delay: how long data takes to travel from one place to another, measured in milliseconds (ms). Lower latency means less delay.

Think of a motorway: bandwidth is how many lanes it has, so how many cars can pass each second. Latency is how long one car takes to reach the end. A road can be wide but slow, or narrow but quick.

Wired and wireless connections

≈ 1.5 min

Ethernet (wired)

  • Uses a cable to a switch or router.
  • + Fast, stable and reliable, with little interference.
  • + More secure: someone needs a physical connection to the cable.
  • − Installing cables and ports costs money. Devices are fixed in place.

Wi-Fi (wireless LAN)

  • Connects devices to a LAN using radio waves.
  • + Devices can move around anywhere in range.
  • + Easy and cheap to add new devices, with no cables to fit.
  • − Usually slower and less reliable. Walls and other devices cause interference.
  • − Signals travel through the air, so they could be intercepted. They need encryption and a strong password.

Bluetooth

  • Very short range (about 10 m) and low power.
  • Links two nearby devices directly ("pairing"), such as a phone and a smartwatch, speaker or keyboard.
  • Not used to connect computers to a LAN.

Network topologies

≈ 2 min

A topology is the layout of how devices in a network are connected.

Star topology

Each device has its own cable to a central switch. Devices are not cabled to each other.

Mesh topology

Devices connect to many other devices, so there are several routes between any two of them.

Star: what to know

  • Every device depends on the central switch.
  • Each cable connects one device only, so think about who is affected if a cable or the switch fails.
  • Easy to add a new device: just run one cable to the switch.
  • Needs a lot of cable, because every device has its own.

Mesh: what to know

  • If one link breaks, data can take another route.
  • This gives reliability (also called "redundancy").
  • Expensive: needs lots of cables or connections.

Drawing a network diagram

  • Count exactly the number of devices the question asks for.
  • Label every device, including the central one.
  • Draw every connection with a clear line.
